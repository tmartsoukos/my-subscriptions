# Το Dashboard μου

Προσωπικό dashboard ως PWA: συνδρομές, εργασίες, ημερολόγιο υποχρεώσεων, σημειώσεις και λίστα «να δω / να διαβάσω».
Ζωντανά: <https://tmartsoukos.github.io/my-subscriptions/>

## Τι κάνει

- **Συνδρομές** — επόμενη χρέωση, μηνιαίο και ετήσιο κόστος, κατηγορίες, εικονίδια υπηρεσιών.
  - Δωρεάν δοκιμές με προειδοποίηση πριν τη λήξη.
  - Μοιρασμένες συνδρομές: υπολογισμός μεριδίου και παρακολούθηση ποιος έχει πληρώσει.
  - Στοιχεία λογαριασμού: τρόπος πληρωμής, email, σύνδεσμος ακύρωσης.
- **Εργασίες** — προτεραιότητες, προθεσμίες, σύρσιμο για ολοκλήρωση/διαγραφή με αναίρεση, φωνητική καταχώριση.
- **Ημερολόγιο** — μηνιαία προβολή με υποχρεώσεις και πληρωμές μαζί.
- **Σημειώσεις** — τίτλος, markdown, εικόνες, καρφίτσωμα, αυτόματη αποθήκευση.
- **Σπουδές** — μαθήματα με ECTS, βαθμούς και σταθμισμένο μέσο όρο· εργασίες και προθεσμίες ανά μάθημα.
- **Υγεία** — ραντεβού, εξετάσεις με επανάληψη, εμβόλια, φάρμακα.
- **Λίστα** — ταινίες, σειρές, βιβλία με κατάσταση και βαθμολογία.
- **Apple Calendar** — ροή webcal που ανανεώνεται μόνη της (πληρωμές, υποχρεώσεις, υγεία).
- **Widget iPhone** μέσω Scriptable, σε αρχική οθόνη και οθόνη κλειδώματος.
- **Siri** — σύνοψη μήνα, τι έχω σήμερα, προσθήκη εργασίας με φωνή μέσω Συντομεύσεων.

## Τεχνικά

Στατικό frontend σε GitHub Pages (vanilla ES modules, χωρίς build step) με Supabase για δεδομένα και αυθεντικοποίηση.
Όλοι οι πίνακες έχουν RLS ανά χρήστη. Offline: προβολή τελευταίων δεδομένων μόνο για ανάγνωση.

```
index.html            κέλυφος εφαρμογής
css/app.css           στυλ
js/                   modules (router, db, ui, charts, logos, voice, markdown, views/)
supabase/functions/   ics-feed (ημερολόγιο), widget-data (widget), assistant (Siri)
supabase/migrations/  SQL σχήματος
scriptable/           script widget για iOS
```

## Widget σε iPhone (Scriptable)

Το iOS δεν επιτρέπει widgets από PWA. Λύση χωρίς Xcode:

1. Εγκατάστησε το **Scriptable** από το App Store.
2. Νέο script (+) και επικόλλησε το [`scriptable/dashboard-widget.js`](scriptable/dashboard-widget.js). Ονόμασέ το «Dashboard».
3. Στην εφαρμογή: **Ρυθμίσεις → Widget iPhone**, αντίγραψε το token και βάλ' το στη γραμμή `TOKEN` του script.
4. **Αρχική οθόνη**: παρατεταμένο πάτημα → **+** → Scriptable → μέγεθος → στο widget διάλεξε *Script: Dashboard*.
5. **Οθόνη κλειδώματος**: Ρυθμίσεις → Φόντο οθόνης → Προσαρμογή → περιοχή widget → Scriptable.

Το widget δείχνει την επόμενη πληρωμή, το μηνιαίο σύνολο, τις εκκρεμείς εργασίες και την επόμενη υποχρέωση.
Ανανεώνεται περίπου κάθε 30 λεπτά και κρατά τα τελευταία δεδομένα όταν δεν υπάρχει δίκτυο.

## Στήσιμο σε δικό σου Supabase

1. Νέο project και εκτέλεση των αρχείων `supabase/migrations/*.sql` με τη σειρά.
2. Deploy των δύο edge functions με `verify_jwt` απενεργοποιημένο (η πρόσβαση ελέγχεται με token).
3. Ενημέρωση του `js/config.js` με το URL και το publishable key του project.
